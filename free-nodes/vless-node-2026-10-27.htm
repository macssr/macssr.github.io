二、何为“云免设置”？——让配置随风而动

“云免”这个词，听起来有些玄妙，但拆解开来看并不复杂。传统模式下，你需要自己购买VPS、搭建服务端、生成节点链接，再手动填入手机。而“云免”则是指：服务提供商或技术团队将已经优化好的配置文件（包括节点信息、分流规则、TLS参数等）存放在云端服务器上。用户只需要在Shadowrocket中添加这个云配置的订阅地址（URL），应用便会自动拉取、解析并生成一套完整的代理环境。

这种模式的优势是显而易见的：

  1. 零门槛上手：你不再需要理解什么是“端口混淆”，什么是“SNI”，只需一个URL，一切自动完成。
  2. 动态实时更新：当你的服务商调整了服务器线路，或修复了某个节点故障时，他们只需更新云端文件。你这边只要在应用内下拉刷新，或者重启一下代理，就能立即获得最新配置，无需手动删除旧节点再逐一添加新节点。
  3. 多设备无缝同步：如果你拥有iPhone、iPad多台设备，使用同一个云订阅地址，配置将保持一致。免去了每台设备分别设置的烦恼，真正实现“一处更新，处处同步”。
  4. 规则策略集中管理：云端配置里通常已经内置了精心调校的分流规则。例如，将国内视频、音乐、购物网站标记为直连，将Google、GitHub、Twitter等标记为代理。这既保证了访问速度，又避免了不必要的流量浪费。

点评： 云免设置的本质，是将“专家级”的配置经验以极低的成本分享给每一位普通用户。它消弭了技术鸿沟，让网络自由不再只是极客的特权。

第二步：寻找可靠的云配置服务源

这一步是关键，也是最需要谨慎的地方。云配置源通常由第三方团队或个人维护。你可以通过技术论坛、社区推荐或朋友介绍获取。一个优质的云配置源，应当具备以下特征： - 节点质量高：拥有多条不同线路（如IEPL、IPLC、原生IP等），延迟低且稳定。 - 更新频率快：能够及时应对特殊时期或节点故障。 - 服务态度好：提供使用文档或客服支持。

获得服务商提供的“订阅链接”后，注意保护好它，这相当于你使用该服务的凭证。

第三步：在Shadowrocket中添加云配置

  1. 打开Shadowrocket，点击底部的“配置”标签。
  2. 在配置页面右上角，点击“+”号图标，选择“添加类型”。
  3. 在弹出的菜单中，选择“订阅”或“URL”（具体名称可能因版本而异，但核心逻辑一致）。
  4. 在“URL”输入框中，粘贴你从服务商那里获取的完整订阅地址（通常以https://开头）。
  5. 在“别名”或“备注”栏中，可以输入一个便于识别的名称，例如“我的主力线路”或“备用机场”。
  6. 点击右上角的“保存”或“完成”。

此时，Shadowrocket会自动向后端服务器发送请求，拉取配置文件。你会看到界面出现一个或多个节点信息，以及自动生成的分流规则。

第四步：启用代理并选择节点

  1. 回到Shadowrocket的“首页”标签。
  2. 在“全局”或“配置”栏下方，你会看到刚才添加的云配置中的节点列表。点击任意一个节点，右侧会出现“连接测试”的选项，建议先测试一下延迟，选择数值最低、最稳定的那个。
  3. 点击顶部的“连接”开关（一个类似网络信号的图标），将其切换为开启状态。
  4. 首次开启时，iOS系统会提示“Shadowrocket想要添加VPN配置”，请点击“允许”，并验证你的Face ID或密码以授权。
  5. 授权完成后，状态栏会出现一个VPN图标，表示代理已成功接管网络流量。

第五步：验证与优化体验

打开Safari浏览器，尝试访问一下之前无法打开的网站（如YouTube、Instagram等）。如果能顺利加载，恭喜你，云免设置已大功告成。

四、进阶技巧与常见问题排查

即便云免设置已经足够智能，但在实际使用中，仍可能遇到一些小插曲。掌握以下技巧，能让你更加从容。

问题一：连不上，提示“连接超时”或“服务器无响应”

  • 排查步骤：首先，检查你的设备是否处于正常的网络环境（蜂窝数据或家用Wi-Fi）。其次，在Shadowrocket的节点列表中，尝试切换其他节点。如果所有节点都超时，可能是你的网络运营商屏蔽了VPN协议，或者你的云服务源已失效。此时，请联系服务商确认订阅状态。
  • 进阶操作：尝试在“设置”中，将“连接类型”从“自动”改为“HTTPS”，或开启“混合代理”模式，这有时能绕过部分网络限制。

问题二：网速很慢，视频卡顿

  • 排查步骤：选择延迟更低、负载更小的节点。如果所有节点都慢，可能是你的网络本身带宽有限，或者服务商正处于高峰期。
  • 进阶操作：在“配置”的规则中，确保国内视频网站（如B站、腾讯视频）走的是“直连”策略。这能有效减轻代理服务器的负担，提升国内访问速度。

问题三：部分App无法联网，但浏览器正常

  • 原因分析：某些App可能开启了“本地网络”权限校验，或者其域名在分流规则中被错误地代理了。
  • 解决方案：进入Shadowrocket的“配置”编辑，在“规则”中添加一条“直连”规则，将特定App的域名或IP段排除在代理之外。或者，在“首页”的“设置”中，找到“按需求连接”，关闭它，确保所有流量都经过代理。

问题四：如何更新云端配置？

  • 操作指南：在“配置”页面，长按你添加的云订阅条目，或左滑点击“更新”按钮。Shadowrocket会重新拉取云端文件，替换旧配置。建议定期更新，以获取最新节点和优化规则。

点评： 排查问题的过程，其实是对网络原理的一次深入学习。掌握了这些技巧，你便不再是一个被动的使用者，而是能主动驾驭网络环境的掌控者。

AEAD 加密能防止流量被篡改或重放，并隐藏流量特征。在高封锁网络中，使用 AEAD 可以提高节点稳定性和长期可用性，同时确保数据安全和隐蔽性。
Nekoray 如何实现节点订阅自动更新？
用户可添加订阅 URL，Nekoray 定期自动下载并更新节点。这样可保持节点列表最新，有效减少手动维护，提高使用效率，同时保证网络连接稳定和可靠。
V2Ray 的 gRPC 模式适合哪些场景？
gRPC 支持多路复用和长连接，适合高并发访问和移动网络场景。相比 TCP 或 WebSocket，它可以减少握手次数，降低延迟，同时提高连接稳定性和吞吐量，特别适合游戏或即时通讯。
Trojan-Go 的端口不可达怎么办？
