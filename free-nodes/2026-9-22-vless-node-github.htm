第一章 认识两大技术核心

1.1 小火箭：移动端代理的优雅解决方案

这款诞生于2015年的iOS应用，凭借其极简主义设计哲学和强大的协议兼容性，逐渐成为App Store网络工具类别的明星产品。最新版本3.0架构重构后，其核心优势体现在三个方面：
- 多协议枢纽：支持SS/SSR/Vmess等12种传输协议
- 智能分流系统：基于域名、IP、地域的精细化流量管理
- 硬件级优化：针对Apple M系列芯片特别优化的加密加速

1.2 V2Ray：下一代代理协议的标杆

Project V团队开发的V2Ray之所以能后来居上，关键在于其模块化架构设计。不同于传统代理工具的单一协议栈，V2Ray的核心创新包括：
- 多路复用技术：单连接并发传输多个数据流
- 动态端口分配：有效对抗深度包检测（DPI）
- 伪装协议库：可模拟HTTP/WebSocket等常规流量

技术点评：当小火箭的优雅交互遇上V2Ray的工程美学，这种"前端简洁+后端强大"的组合，恰如iOS系统与A系列芯片的完美配合，形成了1+1>2的技术协同效应。

第二章 配置实战全流程

2.1 环境准备阶段

版本验证要点：

- 建议关闭iOS私有地址功能（Wi-Fi设置→i图标）

2.2 配置文件获取艺术

资深用户应当掌握三种配置获取方式：
1. 订阅链接法：长按小火箭首页→新建订阅→粘贴V2Ray订阅URL
2. 二维码扫描：对代理服务商提供的配置二维码进行相机识别

2.3 高阶参数调优指南

在「编辑配置」→「参数设置」中，这些选项值得关注：

FAQ

VMess TLS 与 WebSocket 组合有哪些优势？
TLS + WebSocket 可将 VMess 流量伪装为 HTTPS，隐藏真实通信特征。结合策略组使用，可增强抗封锁能力，提高节点稳定性和访问速度，特别适合视频和游戏场景。
QuantumultX 的重写脚本可以实现哪些功能？
QuantumultX 支持 JavaScript 重写脚本，可修改请求头、响应内容、跳转 URL、广告屏蔽和定制化流量处理。结合策略组可实现个性化网络访问和优化，提高用户体验。
Matsuri 节点延迟排序功能如何使用？
Matsuri 会自动测试节点延迟，并根据结果排序。用户可以选择延迟最低的节点使用，从而优化访问速度和稳定性，尤其适合游戏、视频和海外网站加速。
Mellow 如何配置透明代理？
Mellow 通过 tun2socks 技术实现透明代理。只需在配置文件中启用该功能，系统所有网络流量都会自动转发到代理内核，用户无需手动设置系统代理参数。
SSR 的协议插件如何增强连接稳定性？
SSR 的协议插件可以增加流量的伪装特性，模拟常见协议或浏览器行为，从而降低被识别和封锁的风险。这对不稳定网络或高封锁环境尤其有帮助。
WinXray 的测速功能如何使用？
WinXray 内置节点测速工具，可以通过延迟测试（ping）或带宽测试判断节点质量。用户只需右键节点选择“测速”即可，测试结果将显示在列表中，帮助快速挑选最佳线路。
Potatso Lite 支持节点手动导入和修改吗？
支持。用户可以手动输入节点信息或通过扫描二维码导入节点，并进行修改或删除。虽然不支持自动订阅更新，但足以满足轻量级用户对节点管理和分流的需求。
Nekoray 节点订阅更新失败怎么办？
首先检查订阅 URL 是否有效，再确认网络是否通畅。必要时可手动刷新或重新添加订阅链接，保证节点列表最新。结合策略组可保证稳定连接和科学上网体验。
Hiddify Next 支持 Reality 吗？
支持。Hiddify Next 基于 sing-box 内核，可加载 Vless+Reality、Trojan+TLS 等高级协议配置。用户可直接导入机场订阅，无需手动修改复杂参数。
Hiddify Next 的用户管理面板有哪些功能？
Hiddify Next 面板可添加或删除用户、设置带宽限制、生成订阅链接、查看流量统计和节点状态。它提供直观的图形界面，无需命令行操作即可管理服务器资源。
